# Тренажёр партий

Нативное Android-приложение (Kotlin, Jetpack Compose, Material 3): загрузите ноты, выберите свой голос,
слушайте партию кликабельными нотами и проверяйте пение через микрофон. **Своего сервера нет**, всё работает на
устройстве; единственный необязательный внешний вызов — запрос к API Anthropic с ключом самого пользователя.

## Статус

| Часть | Состояние |
|---|---|
| `:core` (чистый Kotlin/JVM): модель, парсеры MusicXML/MXL/MIDI, экспорт, раскрытие повторов, определение голосов, YIN, оценка пения, разбор ответов Claude, правки с undo/redo | **Готово, 63 юнит-теста проходят** (`gradle -c settings-core.gradle.kts :core:test`) |
| `:app` (Android, Compose, Room, DataStore, WorkManager, AudioTrack, AudioRecord) | Написано целиком, **но не собиралось в среде разработки**: из неё недоступен Google Maven/Android SDK. Первая сборка в CI или Android Studio может потребовать мелких правок компиляции |
| Движок «Claude Vision» | Реализован (запросы, повторы, проверка сумм тактов, отмена, оценка стоимости) |
| Движок «На устройстве» (homr) | **Пробный этап не пройден**, интерфейс готов, движок отмечен «недоступен» — причины в [docs/OMR_ON_DEVICE.md](docs/OMR_ON_DEVICE.md) (Andromr — Python/Kivy, а не Android-библиотека; homr/Andromr — AGPL-3.0) |
| Встроенный пример «Верхом на звезде» | Готово (данные в `core/.../BuiltinSong.kt`, помечен «пример, возможны неточности») |

## Структура

```
parts-trainer/
├── core/      чистый Kotlin (JVM): model, music, io, voices, structure, omr, audio, edit  + тесты
├── app/       Android: data (Room/DataStore/Keystore), audio (Synth/Playback/Mic), omr (движки, PdfRenderer, WorkManager), ui (Compose)
├── docs/      OMR_ON_DEVICE.md
├── PRIVACY.md, THIRD_PARTY_LICENSES.md
└── settings-core.gradle.kts   сборка только :core без Android SDK
```

Архитектура: MVVM (`ViewModel` + `StateFlow`), ручной DI (`AppContainer`), корутины/Flow.
Данные: Room (проекты, кэш распознавания по SHA-256 файла), DataStore (настройки), файлы во внутреннем хранилище,
ключ API — AES-GCM с ключом в Android Keystore.

## Сборка

```bash
# только логика (быстро, без Android SDK)
gradle -c settings-core.gradle.kts :core:test

# приложение (нужен Android SDK 35 и JDK 17)
./gradlew :core:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
./gradlew :app:connectedDebugAndroidTest      # инструментальные тесты экранов (эмулятор/устройство)
```

CI (`.github/workflows/`): `android.yml` — юнит-тесты, lint, отладочный APK; `release.yml` — подписанный AAB по
тегу `v*` (секреты `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`).

## Что умеет

* Источники: пример, PDF (системный диалог, «Открыть с помощью», «Поделиться»), фото (камера/галерея),
  MusicXML (`.musicxml`, `.xml`, `.mxl`), MIDI, ручной ввод.
* Выбор строки для PDF/фото: вокал / правая рука / левая рука / все; миниатюры страниц с приблизительной подсветкой
  нотоносцев, выбор страниц, поворот.
* Редактор: проверка после распознавания (сомнительные такты подсвечены), правка высоты/длительности/слога,
  пауза↔нота, лига, разделение, удаление, undo/redo, проигрывание тактов, маркеры повторов вручную.
* Тренажёр: фразы, чипы нот, клавиатура, темп, транспонирование ±12, остальные голоса с отдельной громкостью,
  метроном-отсчёт, раскрытие повторов (`|: :|`, вольты, D.S./D.C., Coda, Fine), экспорт MIDI/MusicXML.
* Проверка пения: YIN (4096 окно, параболическая интерполяция, 70–1000 Гц), допуск ±40 центов (настраивается),
  «Спой фразу» с итогом по каждой ноте.

## Известные ограничения / дальнейшие шаги

* Распознавание нот вместе с текстом песни не делается (по заданию); слоги вводятся вручную.
* Подсветка нотоносцев на миниатюре — эвристика по линейкам (3 нотоносца в системе → вокал/правая/левая).
* Редактор показывает миниатюру только первой распознанной страницы.
* Модель стоимости Claude Vision — оценка с константами цен в `ClaudeOmr.estimate`; проверьте актуальные цены.
* Лицензия проекта не выбрана; от неё зависит возможность подключить homr (AGPL-3.0).
* Нет Oboe: синтезатор на `AudioTrack` (режим `LOW_LATENCY`) — достаточно для нот, при необходимости можно заменить.

## Чек-лист Google Play (Data Safety)

- [ ] «Собирает ли приложение данные?» — **Нет** (по умолчанию). Если включить Claude Vision, считайте это
      передачей «Фото и видео»/файлов стороннему сервису по инициативе пользователя; опишите в разделе
      «Передаётся третьим лицам (Anthropic) — по выбору пользователя, необязательно».
- [ ] Данные шифруются при передаче — да (HTTPS). Можно запросить удаление — да (удаление партий / данные приложения).
- [ ] Разрешения: `RECORD_AUDIO` (проверка пения, запрос при первом включении), `INTERNET` (только Claude Vision),
      `FOREGROUND_SERVICE_DATA_SYNC` и `POST_NOTIFICATIONS` (фоновое распознавание).
- [ ] Загрузить политику конфиденциальности (`PRIVACY.md`, текст есть и в приложении: «О приложении → Политика»).
- [ ] Декларация foreground-сервиса типа `dataSync` (Play Console → Содержание приложения).
- [ ] Выбрать лицензию и обновить `THIRD_PARTY_LICENSES.md`; указать контакт разработчика.
- [ ] Рейтинг контента, целевая аудитория, скриншоты (телефон + планшет 7"/10").
