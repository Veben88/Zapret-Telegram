# Сверка распознавания с эталонным MusicXML

1. Выгрузить токены распознавания страниц (PNG шириной 1920, например `pdftoppm -scale-to-x 1920 -scale-to-y -1 -gray -png score.pdf p`):

   ```
   HOMR_MODELS=<папка с моделями> HOMR_DUMP="<папка>:p-1,p-2:<out.tok>" \
     gradle -c settings-core.gradle.kts :omr:test --rerun --tests '*dumpTokens*'
   ```

2. Сравнить с эталоном (распакованный .mxl → .xml); `0:P1` — строка 0 каждой системы соответствует партии P1:

   ```
   python3 tools/omr_eval/compare.py score.xml out.tok 0:P1,1:P2,2:P3
   python3 tools/omr_eval/diff.py score.xml out.tok 1 P2 0     # расхождения строки 1, верхний голос
   ```

   Строка в ключе «соль с 8»: в MusicXML записана звучащая высота, поэтому сдвиг: `1:P2:-12` (в `diff.py` — шестой
   аргумент `-12`).

Для каждой партии берутся верхняя и нижняя линии нот (по моментам начала нот), лиги объединяются, затем
последовательности выравниваются (расстояние Левенштейна): «высоты» — совпадение высот, «высоты+длительности» — и длительностей.

## Полная сверка: цифровые PDF и сканы (Sprint 0)

Один прогон считает по каждому набору страниц и отдельно по типам (`digital`, `synthetic-scan`, `scan`, …):

* **Высоты %**, **Длит. %**, **Выс.+длит. %** — по верхней и нижней линии нот партии, лиги слиты (как `compare.py`);
* **SER %** (Symbol Error Rate) — по напечатанным символам (верхняя нота или пауза с длительностью, без слияния лиг):
  вставки + удаления + замены / число символов эталона;
* **Recall нотоносцев** — найдено / ожидалось по страницам (`staves` в манифесте, числа считаются вручную);
* **время** страницы (медиана) и по этапам, **пик RSS** (память процесса, включая ONNX Runtime).

```
HOMR_MODELS=<папка с моделями> HOMR_EVAL=<manifest.json> HOMR_EVAL_OUT=<папка отчёта> \
  gradle -c settings-core.gradle.kts :omr:test --rerun --tests '*OmrEvalTest.evaluate*' -i
```

Формат манифеста — `manifest.example.json`; `map` — «строка в системе:партия[:сдвиг в полутонах]». Отчёт:
`report.md` и `report.json`. Ноты пользователей в репозиторий не кладутся — манифест и страницы держите вне его.

Синтетические «сканы» из чистых страниц (наклон, размытие, шум, неровная яркость, JPEG; 300/200/150 dpi; результат
воспроизводим):

```
python3 -I tools/omr_eval/make_scan.py <папка> p-1,p-2 <папка-выхода>
```

Положения нот на исходной странице (точка ноты → исходник, есть ли рядом головка ноты; для сравнения — точки, сдвинутые
на 2 интервала):

```
HOMR_MODELS=<папка> HOMR_POS="<папка>:p-1,p-2" gradle -c settings-core.gradle.kts :omr:test --rerun --tests '*NotePosition*' -i
```

Склейка окон SegNet (сравнение способов на страницах и на размерах, не кратных 320):

```
HOMR_MODELS=<папка> HOMR_SEGMERGE="<папка>:p-1,p-2" gradle -c settings-core.gradle.kts :omr:test --rerun --tests '*SegnetMergeExperiment*' -i
```
