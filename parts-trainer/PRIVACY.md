# Политика конфиденциальности — «Тренажёр партий»

Дата редакции: 2026-11-03

У приложения **нет собственного сервера**. Аналитики, рекламы, трекеров и скрытой отправки данных нет.

| Данные | Что происходит |
|---|---|
| Микрофон | Нужен только для проверки пения. Звук анализируется на устройстве в реальном времени, **не записывается и не отправляется**. Разрешение `RECORD_AUDIO` запрашивается при первом включении проверки. |
| Файлы нот (PDF, фото, MusicXML, MIDI) | Копируются во внутреннее хранилище приложения и не покидают устройство. |
| Движок «Claude Vision» (необязательный) | **Единственный случай, когда данные уходят с устройства.** Если вы сами выбрали этот движок и задали свой ключ API, изображения нотных страниц отправляются напрямую с телефона в Anthropic (`api.anthropic.com`). Запросы платные, оплачиваются вашим ключом. Перед первым использованием приложение показывает предупреждение. К Anthropic применяется его собственная политика конфиденциальности. |
| «Распознавать слова песни» (необязательно, выключено по умолчанию) | Только при включении в настройках и заданном вашем ключе: узкие полоски страницы с текстом под нотоносцами (не вся страница) отправляются напрямую в Anthropic (`api.anthropic.com`) для чтения слов. Платно, по вашему ключу. Без ключа слова не распознаются, ноты читаются полностью офлайн. |
| Резервная копия (по вашему действию) | Создаётся только по кнопке «Сохранить копию» в настройках: один ZIP с партиями и исходными файлами, который вы сохраняете сами куда выберете. Приложение его никуда не отправляет. Автоматическое облачное копирование отключено. |
| Ключ API | Хранится только на устройстве в зашифрованном виде (AES-256-GCM, ключ в Android Keystore), не логируется. Можно удалить в Настройках. |
| Резервные копии | Автоматическое резервное копирование и перенос данных отключены (`allowBackup=false`, правила исключают все данные). |
| Удаление | Удалите партию в списке или очистите данные приложения в настройках Android. |

Контакт для вопросов: укажите в карточке Google Play (поле «Электронная почта разработчика»).
